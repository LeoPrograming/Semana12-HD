# Sistema de Registro de Usuarios — práctica UTP

Proyecto de demostración para practicar **GitHub Issues, etiquetas, prioridades, ramas, commits y Pull Requests**.

## Ejecutar
Abre `index.html` con tu navegador. No requiere servidor ni instalaciones.

## Issue intencional pendiente
El botón **Limpiar** no funciona porque en `index.html` tiene `type="button"` en vez de `type="reset"`. Este es el defecto que se corregirá mediante un Pull Request real.

## Nota académica
Es una aplicación ficticia de práctica. El registro funciona en memoria; no hay autenticación ni base de datos. Los Issues adicionales de inicio de sesión, visualización y estilos son escenarios propuestos, no fallas observadas en esta demo.
